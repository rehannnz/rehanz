# Rehan Fashion

Website katalog baju dan celana, siap untuk GitHub Pages.

## File utama
- `index.html` — struktur halaman
- `style.css` — desain dan layout responsif
- `script.js` — daftar produk, filter kategori, dan tombol WhatsApp

## Catatan
Nama toko dibuat sebagai **Rehan Fashion**. Harga dan gambar pakaian adalah ilustrasi/contoh tampilan, bukan daftar stok aktual. Sesuaikan nama, harga, dan deskripsi di `script.js` sebelum dipublikasikan.

## Upload ke GitHub Pages
1. Buat repository baru.
2. Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
